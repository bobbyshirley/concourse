# Concourse — Event Operations Platform

**Concourse** is a modern, real-time web application designed to coordinate guest logistics, host assignments, travel schedules, and seating for large-scale conferences and events from a single operational system.

Designed to replace fragmented spreadsheets, messaging threads, and discrete boards with a live command center.

---

## 🚀 Features (Milestone 1)

- **Live Command Dashboard**: Real-time KPI summary tracking guest count, delays, pending transportation, and check-ins.
- **Guest Master Records**: Centralized tracking for host assignments, travel routes, hotel rooms, and dietary requirements.
- **Global Activity Stream**: Real-time operational audit log tracking flight landings, check-ins, and transport status.
- **Guest Flyout Inspector**: Slide-out detail view for viewing guest timelines and editing master records.
- **Dark-mode Modern UI**: Built with a sleek visual language inspired by Linear and Vercel.

---

## 🛠️ Tech Stack

- **Language**: TypeScript
- **Styling**: Tailwind CSS
